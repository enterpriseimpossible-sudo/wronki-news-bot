# ADR 0001 — GitHub Actions як планувальник

- **Статус:** прийнято (з обмеженням).
- **Контекст:** бот має працювати без виділеного сервера.
- **Рішення:** GitHub Actions кожні ~10 хв + самоланцюжок; `state.json` у кеші.
- **Наслідки:** без `schedule`/watchdog канал замовкає після збою; потрібен токен зі scope `workflow`.
