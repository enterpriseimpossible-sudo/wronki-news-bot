# Телеграм-бот «Новини Вронки та околиць» — інструкція

Це окремий проєкт (не пов'язаний з аудитом акаунтів). Папка: `C:\Users\enter\Desktop\Телеграм_новини_вронки_і_околиці`.

Бот збирає новини з багатьох джерел Вронок та околиць (гміни, поліція, пожежна, медіа, Telegram-канали) і публікує у твоєму Telegram-каналі. Налаштовується у командному центрі (панель).

> **СТАТУС: ПРАЦЮЄ (2026-10-10).**
> - Python 3.13.16; у проєкті `.venv` із залежностями.
> - Бот: **@wronki_news_ua_bot** (токен у `.env`).
> - Канал: **«Новини Вронки та околиці»**, бот — адміністратор (id `-1004353266588`).
> - **Командний центр (панель):** ярлик на робочому столі «Командний центр — Новини Вронки» або `panel.bat` → http://127.0.0.1:8765.
> - **Режим:** публікація ОДРАЗУ, як з'явиться на сайті (завдання Windows `WronkiNewsBot`, перевірка кожні 5 хв).
> - **Джерела:** 20+ (гміни Вронки/Шамотули/Любаш/Пнєви/Хжипсько/Оборніки…, поліція, пожежна, медіа, Telegram-канали). Радіус за замовчуванням 30 км.
> - Запуск вручну: `run.bat`. Панель: `panel.bat` або ярлик.
> - Косметика каналу (аватар/опис/закріплений пост) — вручну в застосунку, див. `brand/ЯК_ОФОРМИТИ.md`.

## 0. Що робить бот
- Бере свіжі новини з **RSS** `https://wronki.pl/rss/aktualnosci.xml` (найнадійніше джерело) та, як додаток, з HTML-сторінок `wronki.pl/aktualnosci/` і `szamotuly.policja.gov.pl`.
- Пам'ятає, що вже публікував (файл `state.json`) — не дублює.
- Публікує у канал: заголовок, опис, фото (якщо є), дата, посилання.
- Режим `DRY_RUN=1` — нічого не постить, лише показує в консолі (для перевірки).

## 1. Що знадобиться (чекліст)
- [ ] Python 3.10+ на ПК (**зараз на твоєму ПК його немає — лише заглушка Microsoft Store**).
- [ ] Токен бота від **@BotFather**.
- [ ] Telegram-канал для новин + бот доданий туди **адміністратором**.
- [ ] Файл `.env` з токеном і id каналу.

---

## 2. Крок 1. Встановити Python
1. Відкрий https://www.python.org/downloads/ → **Download Python 3.x**.
2. У вікні інсталятора **обов'язково постав галочку «Add python.exe to PATH»** (внизу вікна), тоді «Install Now».
3. Перевір: відкрий PowerShell і виконай:
   ```
   python --version
   ```
   Має показати щось на кшталт `Python 3.12.x`. Якщо відкривається Microsoft Store — Python не встановлено, спробуй іще раз (галочка Add to PATH).

> Альтернатива через той самий Store: у Microsoft Store знайди «Python 3.12» і встанови — тоді команда `python` теж працюватиме.

## 3. Крок 2. Створити бота і взяти токен (@BotFather)
1. У Telegram відкрий чат **@BotFather**.
2. Надішли `/newbot`.
3. Введи назву бота (напр. `Новини Вронки`).
4. Введи username, який закінчується на `bot` (напр. `wronki_news_ua_bot`).
5. BotFather видасть **токен** виду `123456789:AA...`. Це секрет — нікому не передавай і не викладай у код.

## 4. Крок 3. Створити канал і додати бота
1. У Telegram: «Створити канал» → назва (напр. «Новини Вронки та околиць») → публічний або приватний.
2. У каналі: **Керування → Адміністратори → Додати** → знайди свого бота → дай право **Публікувати повідомлення**.
3. Дізнайся `chat_id` каналу:
   - Для **публічного** каналу можна просто вказати `@username_каналу` (напр. `@wronki_news`).
   - Для **числового id**: напиши будь-яке повідомлення в канал, тоді відкрий у браузері
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайди `"chat":{"id":-100...}`.

## 5. Крок 4. Налаштувати .env
1. У папці проєкту скопіюй `.env.example` у файл з назвою **`.env`**.
2. Впиши свої значення:
   ```
   TELEGRAM_BOT_TOKEN=123456789:AA...
   TELEGRAM_CHANNEL_ID=@wronki_news
   DRY_RUN=1
   MAX_ITEMS=10
   TRANSLATE=0
   ```
   > `DRY_RUN=1` — для першого тесту (нічого не публікується). Для реальної роботи постав `DRY_RUN=0`.

## 6. Крок 5. Встановити залежності
У PowerShell перейди в папку проєкту й виконай:
```
python -m pip install -r requirements.txt
```

## 7. Крок 6. Тестовий запуск (без публікації)
```
".venv\Scripts\python.exe" bot.py
```
З `DRY_RUN=1` бот друкує, ЩО б він опублікував. Перевір, що новини тягнуться й виглядають нормально. Коли все ок:
- у `.env` постав `DRY_RUN=0`;
- запусти `".venv\Scripts\python.exe" bot.py` — новини підуть у канал.
> Публікація в канал — це вихід назовні. Роби це свідомо.

## 8. Крок 7. Регулярна робота (розклад)
Варіант A — вручну: подвійний клік на `run.bat` (або `".venv\Scripts\python.exe" bot.py`) кілька разів на день.

Варіант B — автоматично (Windows Task Scheduler):
1. «Планувальник завдань» → «Створити завдання».
2. Дія → Запуск програми → програма: `python`, аргументи: `bot.py`, робоча папка: папка проєкту.
3. Тригер: щодня, напр. о 08:00, 13:00, 18:00.

Варіант C — через ER7: скажи «заплануй щогодини запускати бота у папці …» — я створю завдання через `er7_schedule`.

## 9. Джерела новин
У `bot.py` є список `SOURCES`. Основне — RSS Вронок. Можна додати сусідні гміни (Шамотули, Обжицько, Любаш, Серакув, Оборники) — додай їхні RSS/HTML у список. Приклади RSS можна знайти в кінці сторінок «Актуальності» відповідних сайтів.

## 10. Часті проблеми
| Симптом | Причина / рішення |
|---|---|
| `python` відкриває Microsoft Store | Python не встановлено — див. Крок 1 (галочка Add to PATH). |
| `chat not found` | Неправильний `chat_id`, або бота не додано адміністратором каналу. |
| `Unauthorized` | Неправильний токен у `.env`. |
| Нічого не публікується | `DRY_RUN=1` — постав `0`. |
| Немає нових новин | Усі вже в `state.json`; можна видалити файл, щоб почати заново. |
| Порожній переклад | `TRANSLATE=1` використовує безкоштовний сервіс — він нестабільний; за потреби краще відмовитись. |

## 11. Безпека
- Токен — лише у `.env`, не в коді й не в Git. Файл `.env` додано в `.gitignore`.
- `.env`, `state.json` не публікуй.
- Якщо токен витік — @BotFather → `/revoke` і отримай новий.
