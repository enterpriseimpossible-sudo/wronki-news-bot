# GitHub-розклад вимкнено

Причина: GitHub за ~2 години жодного разу не запустив планові (cron) прогони для цього репозиторію — відома примха GitHub на нових репозиторіях із частим розкладом. Тому автозапуск переносимо на постійний сервер (див. `deploy/README_ДЕПЛОЙ.md`).

Що зроблено:
- У файлі `.github/workflows/wronki.yml` прибрано тригер `schedule`.
- Лишився `workflow_dispatch` — ручний запуск (для тестів) через вкладку Actions або панель («Опублікувати зараз»).

Так сервер і GitHub не будуть дублювати одне одного.

Якщо колись захочеш повернути GitHub-розклад (наприклад, сервера не буде) — додай назад у `wronki.yml`:

```yaml
on:
  schedule:
    - cron: "*/15 * * * *"
  workflow_dispatch: {}
```

(рекомендований інтервал — 15–30 хв; частіші розклади GitHub часто ігнорує).
